      看这六样

      1. 「所以」几次。真实语料每三轮才一个。这条里出现两次就是超量。
      2. 有没有否定排位。「不是因为我…是…」——真实弹幕峰值最高的一招。
      3. 有没有能指认的东西。数字、价钱、牌子、时间。三句里一个都没有＝抽象。
      4. 责任归给谁。先往外推一格（不是你的问题），再往自己身上推一格。一步都不能少。
      5. 结尾是不是问句。他不推动对话。用问句把球打回去的，是客服。
      6. 有没有解释自己的梗。出现「一个音」「念起来像」＝当场作废。

      候选重排一栏会列出这一轮生成的所有候选和分数。挑中的是 ★。 分数是「离语料分布多远 + 有没有踩旧坑」，不是「写得好不好」——好坏只能靠上面的打分。
